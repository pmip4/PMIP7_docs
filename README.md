# PMIP7_docs
This repository relates to PMIP7 documentation. It holds both information about PMIP7, which will be ported to the PMIP website and information about UK contributions to PMIP7.

_It is meant as an internal resources for the community, and may easily not make sense to people outside that community_.

## Useful Links

The [PMIP Website](https://pmip.lsce.ipsl.fr/) and the [CMIP website](https://wcrp-cmip.org/)

[Inventory of CMIP7](https://www.climate-resource.com/tools/esm-model/cmip7-availability) simulations, including which datasets align with the [Paleo-opportunity](https://www.climate-resource.com/tools/esm-model/cmip7-availability/opportunities/51). The actual data can be searched at on the [ESGF itself](https://metagrid-ceda.east.esgf.io/search).

(Inventory of CMIP6)[https://pcmdi.llnl.gov/CMIP6/ArchiveStatistics/esgf_data_holdings/] simulations, including just the (PMIP experiments)[https://pcmdi.llnl.gov/CMIP6/ArchiveStatistics/esgf_data_holdings/PMIP/index.html]. The actual data can be searched at (on the ESGF)[https://metagrid-ceda.east.esgf.io/search].
